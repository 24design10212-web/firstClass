# Dal.Komm 리뉴얼 프로젝트 — Design System

> 목적: 완성된 메인페이지(`dalkomm/index.html`, `dalkomm/css/main.css`)의 실제 구현을 기준으로 서브페이지의 브랜드 정체성과 UI 규칙을 유지합니다.
> 분석 범위: 메인 HTML/CSS, `../CSS/default.css`, `../font/css/pretendardvariable.css`, 프로젝트 내 이미지 자산.
> 원칙: 아래 수치는 현재 코드에서 확인되는 값입니다. 코드에 없는 규칙을 임의의 브랜드 규칙처럼 추가하지 않습니다. 메인페이지는 이 문서를 작성하거나 서브페이지를 제작하는 과정에서 수정하지 않습니다.

---

## 1. Project Overview

### 사이트 목적
달콤(Dal.Komm)과 달콤N의 브랜드, 메뉴, 매장, 새소식, APP 정보를 안내하고 사용자가 각 콘텐츠를 탐색하도록 돕는 브랜드 웹사이트입니다. 메인페이지는 히어로 배너로 시선을 끈 뒤 브랜드 소개 → 시그니처 메뉴 → 이벤트 → 뉴스 순서로 정보를 제공합니다.

### 디자인 방향
- **이미지 중심:** 히어로 배너와 브랜드·메뉴 사진을 크게 사용해 제품과 브랜드 분위기를 먼저 전달합니다.
- **강한 명도 대비:** 흰색·밝은 뉴트럴 배경을 기본으로 하고, 브랜드 소개에는 짙은 회색과 오렌지를 크게 사용합니다.
- **간결한 UI:** 캡슐형 CTA, 원형 슬라이드 버튼, 단순한 화살표 아이콘으로 조작 요소를 구성합니다.
- **정보 위계:** 큰 섹션 제목, 중간 크기 설명, 작은 카테고리·날짜 순으로 읽는 흐름을 만듭니다.
- **콘텐츠별 레이아웃:** 브랜드 소개는 가로 Flex, 이벤트·뉴스는 3열 Grid, 푸터는 Grid를 사용합니다.
- **반응형:** 1024px과 600px을 주요 전환점으로 사용하고, 히어로 컨트롤에는 480px 보정 규칙이 있습니다.

서브페이지는 메인페이지의 섹션을 그대로 복제하지 않습니다. 색상, 폰트, 여백, 버튼, 이미지 처리, 헤더·푸터의 공통 규칙을 유지하면서 페이지 목적에 맞게 정보구조를 확장합니다.

## 2. Brand Identity

| 요소 | 실제 표현 | 사용 맥락 |
|---|---|---|
| 핵심 오렌지 | `--color-orange-500: #FF671F` | 브랜드 포인트, 강조, hover, 활성 상태 |
| 짙은 뉴트럴 | `--color-neutral-900: #222222` | 기본 텍스트, 짙은 브랜드 패널, 버튼 |
| 밝은 뉴트럴 | `--color-neutral-100: #F7F5F2` | 이벤트 등 콘텐츠 구역 배경 |
| 흰색 | `--color-neutral-0: #FFFFFF` | 기본 배경, 카드·버튼 표면, 반전 텍스트 |
| 로고 | `img/BI.svg`, `img/logo 1.png`, `img/logo 2.png` | 로고는 제공 이미지 사용. 텍스트로 임의 재현하지 않음 |
| 사진·제품 이미지 | `dalkomm/img/`의 실제 이미지 | 브랜드 공간, 메뉴, 이벤트의 시각적 전달 |

### 브랜드별 색 표현
- Dal.Komm 브랜드 패널(`.brand-panel--dalkomm`)은 `var(--color-neutral-900)` 배경과 흰색 텍스트를 사용합니다.
- Dal.Komm.N 패널(`.brand-panel--dalkomm-n`)은 `var(--color-orange-500)` 배경과 흰색 텍스트를 사용합니다.
- 두 패널은 `.brand-panel-inner`, `.brand-copy`, `.brand-image` 구조를 공유하고 배경·콘텐츠 순서 등 필요한 차이만 modifier 클래스로 구분합니다.

브랜드 성격을 표현할 때 오렌지와 짙은 회색을 중심으로 사용하고, 별도의 임의 색상 팔레트를 추가하지 않습니다.

## 3. Design Principles

1. **메인페이지를 기준으로 확장:** 공통 헤더·푸터·색상·폰트·버튼 스타일을 재사용합니다.
2. **색상은 역할에 맞게:** 오렌지는 강조·선택·상호작용에 사용하고, 모든 배경을 오렌지로 채우지 않습니다.
3. **정보 우선순위 유지:** 페이지 제목 → 섹션 제목 → 설명 → 보조 정보 순으로 시각적 위계를 둡니다.
4. **여백으로 콘텐츠 구분:** 섹션 패딩, 제목과 설명 간격, 카드 간격은 서로 다른 역할을 하므로 하나의 숫자로 무리하게 통일하지 않습니다.
5. **이미지 목적에 맞는 자르기:** 제품 전체를 보여줄 때는 `contain`, 공간·배너·카드 사진은 콘텐츠에 맞춰 `cover`를 사용합니다.
6. **공통 UI의 일관성:** 캡슐형 버튼, 원형 아이콘 버튼, 둥근 이미지 모서리 등 반복되는 형태를 유지합니다.
7. **접근성:** 버튼은 실제 `button`, 이동은 `a`를 사용하고 `:focus-visible` 표시를 제거하지 않습니다. 상태는 색상뿐 아니라 클래스·ARIA 속성으로도 표현합니다.
8. **실제 동작 연결:** 새 페이지의 링크는 프로젝트 내부 페이지·섹션 또는 실제 구현된 기능으로 연결합니다.
9. **기존 코드 존중:** `main.css`에는 같은 컴포넌트의 보정 규칙이 뒤쪽에 추가된 부분이 있습니다. 수정할 때는 파일의 최종 적용 규칙을 확인합니다.

## 4. Color System

### CSS 변수 — `dalkomm/css/main.css`의 `:root`

| 변수명 | 값 | 역할 |
|---|---|---|
| `--color-orange-500` | `#FF671F` | 브랜드 핵심 오렌지 |
| `--color-orange-50` | `#FFF0E8` | 연한 오렌지 강조 배경 토큰 |
| `--color-neutral-900` | `#222222` | 기본 짙은 텍스트·짙은 패널 |
| `--color-neutral-200` | `#E5E1DC` | 경계선용 뉴트럴 |
| `--color-neutral-100` | `#F7F5F2` | 부드러운 밝은 배경 |
| `--color-neutral-0` | `#FFFFFF` | 흰색 |
| `--color-background-default` | `var(--color-neutral-0)` | 페이지 기본 배경 |
| `--color-background-subtle` | `var(--color-neutral-100)` | 구분 배경 |
| `--color-surface-default` | `var(--color-neutral-0)` | 기본 UI 표면 |
| `--color-surface-subtle` | `var(--color-neutral-100)` | 보조 UI 표면 |
| `--color-text-primary` | `var(--color-neutral-900)` | 기본 텍스트 |
| `--color-text-inverse` | `var(--color-neutral-0)` | 어두운/강조 배경 위 텍스트 |
| `--color-border-default` | `var(--color-neutral-200)` | 기본 경계선 |
| `--color-action-primary` | `var(--color-orange-500)` | 주요 액션 |
| `--color-action-primary-text` | `var(--color-neutral-900)` | 주요 액션 텍스트 |
| `--color-action-secondary` | `var(--color-neutral-900)` | 보조 액션 |
| `--color-accent-subtle` | `var(--color-orange-50)` | 연한 강조 |
| `--color-accent-strong` | `var(--color-orange-500)` | 강한 강조 |

### 적용 규칙
- 일반 텍스트는 `--color-text-primary`, 흰색 바탕은 `--color-background-default`를 우선 사용합니다.
- 짙은 배경 위에는 `--color-text-inverse`를 사용합니다.
- 오렌지 강조는 `--color-action-primary` 또는 `--color-accent-strong`을 우선 사용합니다.
- 현재 CSS에는 `#888`, `#666`, `#333`, `#999`, `#111` 등 직접 입력된 색도 일부 존재합니다. 해당 컴포넌트의 실제 구현을 확장할 때만 제한적으로 참고하고, 새 전역 팔레트처럼 사용하지 않습니다.
- 정의된 변수라고 해서 모든 페이지에서 이미 같은 방식으로 사용되고 있다고 가정하지 않습니다.

## 5. Typography

### 폰트
- HTML은 `../font/css/pretendardvariable.css`를 연결합니다.
- 기본 글꼴은 `"Pretendard Variable", sans-serif`입니다.
- Pretendard Variable은 가변 굵기 폰트이며, 브랜드 로고는 텍스트가 아닌 이미지 자산을 사용합니다.
- 전역 초기화와 한국어 줄바꿈 규칙은 `../CSS/default.css`를 따릅니다.

### 메인페이지에서 확인되는 주요 크기

### 적용 규칙
- 위 수치는 메인페이지의 해당 역할에 대응하는 참고값입니다. 서브페이지의 모든 텍스트에 그대로 적용하지 말고 제목·본문·카테고리·날짜의 역할에 맞춰 선택합니다.
- 제목의 크기뿐 아니라 굵기, 행간, 자간도 함께 확인합니다.
- 표에 없는 값은 기존 메인페이지의 유사한 콘텐츠 역할을 기준으로 결정하고, 근거 없는 수치를 디자인 시스템의 고정 규칙으로 기록하지 않습니다.

## 6. Layout & Spacing

### 컨테이너
| 영역 | 데스크톱 | 반응형 |
|---|---|---|
| 헤더 내부 | 최종 보정 규칙에서 `width: calc(100% - 10.2%)` | 1024px 이하 64px 좌우 여백, 600px 이하 32px 좌우 여백 |
| 브랜드 패널 내부 | `width: calc(100% - 240px)`, `max-width: 1400px` | 1024px 이하 좌우 40px, 600px 이하 좌우 20px |
| Signature 내부 | `width: calc(100% - 120px)`, `max-width: 1800px` | 태블릿 좌우 32px, 모바일 좌우 16px |
| 이벤트·뉴스 내부 | `width: calc(100% - 120px)`, `max-width: 1600px` | 태블릿 좌우 32px, 모바일 좌우 16px |
| 푸터 내부 | `width: calc(100% - 160px)`, `max-width: 1760px` | 태블릿 좌우 32px, 모바일 좌우 20px |

### 섹션 간격과 구조
- 브랜드 패널은 기본 세로 패딩 70px이며, 태블릿 64px, 모바일 48px 규칙을 사용합니다.
- Signature는 데스크톱 `padding: 132px 0 110px`, 태블릿 `90px 0 80px`, 모바일 `64px 0 60px`입니다.
- 이벤트는 데스크톱 `90px 0 100px`, 태블릿 `72px 0 80px`, 모바일 `56px 0 60px`입니다.
- 뉴스는 데스크톱 `80px 0 100px`, 태블릿 `64px 0 80px`, 모바일 `52px 0 60px`입니다.
- 이벤트·뉴스 카드는 데스크톱 3열 Grid, 모바일 1열입니다.
- 브랜드 패널은 Flex 가로 배치이며, 모바일에서 세로로 쌓습니다. Dal.Komm.N은 이미지와 텍스트 순서가 반대입니다.
- 푸터는 데스크톱 3열 Grid, 태블릿 2열, 모바일 1열로 변경됩니다.

### 이미지 규칙
- 히어로 배너는 `aspect-ratio: 1920 / 680`을 기준으로 표시합니다. 모바일(1024px 이하)은 `.mo` 이미지를 표시하고 원본 비율을 유지합니다.
- 브랜드 사진은 `aspect-ratio: 600 / 380`, `object-fit: cover`를 사용합니다.
- Signature 제품 이미지는 `object-fit: contain`으로 전체 제품이 보이도록 합니다.
- 이벤트 이미지는 `aspect-ratio: 1.58 / 1` 및 `object-fit: cover`를 사용합니다.
- 이미지 모서리는 컴포넌트별로 다릅니다. 브랜드 사진은 데스크톱 24px, 태블릿 18px, 모바일 14px이며 이벤트·뉴스 카드도 각자의 규칙을 따릅니다.

### Flex와 Grid 적용 상황
- 콘텐츠가 이미지와 설명처럼 2개 영역으로 나뉘고 순서가 바뀔 수 있으면 Flex를 사용합니다.
- 이벤트·뉴스처럼 같은 성격의 항목을 반복 배치하면 Grid를 사용합니다.
- 카드 수가 줄거나 화면 폭이 좁아지면 열 수를 조정하고, 작은 화면에서는 1열로 전환합니다.
- 고정 폭보다 `minmax(0, 1fr)`, `clamp()`, `calc()` 등 기존 코드에서 사용한 유연한 크기 지정 방식을 우선 검토합니다.

## 7. Components

### Header / GNB
- 헤더는 `.site-header`의 sticky 구조이며, 로고·중앙 GNB·별도 CTA로 구성됩니다.
- 로고는 `img/BI.svg`를 사용합니다.
- 메뉴 항목은 BRAND, MENU, STORE, NEWS, APP이며 BRAND·MENU·NEWS는 드롭다운을 포함합니다.
- 드롭다운은 흰색 배경, 아래쪽 둥근 모서리, 세로 목록 구조입니다.
- GNB hover/focus는 오렌지색으로 강조합니다. 드롭다운의 항목은 텍스트 색상 변화로 상태를 표시합니다.
- 헤더 관련 규칙은 `main.css` 뒤쪽에 여러 차례 보정 선언이 있으므로 최종 선언을 기준으로 합니다.

### Brand Panel
- 기본 구조: `.brand-panel` → `.brand-panel-inner` → `.brand-copy` + `.brand-image`.
- 두 브랜드는 동일 구조를 사용하고 배경색과 이미지·텍스트 순서를 modifier 클래스로 구분합니다.
- CTA `.brand-link`는 캡슐형이며, hover 시 투명도와 Y축 위치를 조금 변경합니다.

### Signature Tabs / Slider
- 탭은 `.signature-tab`이며 기본 흰색·짙은 테두리, 활성 `.is-active`는 짙은 배경·흰색 글자입니다.
- 제품 이미지는 기본 축소, 활성 슬라이드는 원래 크기로 보이는 확대 효과를 사용합니다.
- 이전/다음 버튼은 원형 테두리 버튼이며 제공된 화살표 이미지 자산을 사용합니다.
- 메인페이지 슬라이드는 이미 저장소에 포함된 Swiper를 사용합니다.

### Event / News Cards
- 이벤트·뉴스는 반복 카드 Grid입니다.
- 이벤트 이미지는 hover 시 `scale(1.035)`로 확대됩니다.
- 뉴스 카드는 `--color-neutral-100` 배경과 둥근 모서리, 내부 패딩을 사용합니다.
- 카드의 카테고리·제목·설명·날짜는 정보 위계를 구분합니다.

### Buttons / Links
- 브랜드 CTA는 둥근 캡슐 형태입니다. 데스크톱 최소 높이는 48px이며 반응형에서 태블릿 42px, 모바일 40px 규칙이 있습니다.
- 이벤트·뉴스 더보기 링크는 테두리형 캡슐 버튼이며 hover 시 짙은 배경과 흰색 텍스트로 반전됩니다.
- 이동에는 `a`, 동작에는 `button`을 사용합니다. 버튼을 링크처럼 사용하거나 링크에 임의의 동작을 넣지 않습니다.
- 링크 텍스트만으로 목적을 알 수 있게 작성하고, 장식용 화살표 이미지는 대체 텍스트를 비워 둡니다.

### Footer
- 로고, 회사 정보, 아이콘 액션, 하단 링크로 구성됩니다.
- 데스크톱에서는 가로 정보 구조, 모바일에서는 세로 구조로 전환합니다.
- 아이콘은 제공 이미지 자산을 사용하며, 실제 목적이 없는 버튼·링크를 새 페이지에서 그대로 복제하지 않습니다.

### 링크 원칙
- 새 서브페이지의 링크는 프로젝트 내부 HTML, 페이지 내 섹션 ID, 실제 구현된 기능으로 연결합니다.
- **새로 제작하는 링크를 기존 달콤 공식 브랜드 사이트로 연결하지 않습니다.**
- 메인페이지에 이미 남아 있는 외부 링크는 이번 작업에서 변경하지 않습니다. 메인페이지를 수정하지 않는 것이 작업 조건입니다.

## 8. Interaction

- GNB와 드롭다운은 hover 및 `:focus-within`으로 열림/강조 상태를 표현합니다. BRAND 드롭다운은 JavaScript의 `.is-open`, `aria-expanded` 상태도 함께 사용합니다.
- 메뉴 hover/focus-visible 색상은 오렌지 `#FF671F` 계열입니다.
- 브랜드 CTA hover는 `opacity: .88`, `translateY(-2px)`, 약 0.2초 전환을 사용합니다.
- 이벤트·뉴스 더보기 링크는 배경·글자색이 약 0.2초 전환되며 반전됩니다.
- 이벤트 이미지는 hover 시 `scale(1.035)`, 약 0.35초 전환을 사용합니다.
- Signature 이미지 확대는 약 0.3초 전환을 사용합니다.
- Signature 탭은 `.is-active`와 `aria-pressed`로 선택 상태를 표시합니다.
- 키보드 사용자를 위한 `:focus-visible` outline을 유지합니다. 메인페이지의 일부 포커스는 2px outline과 4px offset을 사용합니다.
- 전역 `default.css`의 `prefers-reduced-motion: reduce` 설정을 존중합니다.
- hover에만 의존하지 말고 키보드 포커스와 모바일 터치에서도 콘텐츠를 사용할 수 있게 합니다.

## 9. Responsive Rules

주요 breakpoint는 `1024px`, `600px`이며 히어로 컨트롤에는 `480px` 보정 규칙이 있습니다.

### 1024px 이하
- 헤더 높이와 좌우 여백, GNB 간격·글자 크기를 줄입니다.
- 히어로는 PC 배너를 숨기고 모바일 이미지를 표시합니다.
- 브랜드 패널은 좌우 여백과 gap을 줄이고 최소 높이에 의존하지 않도록 구성합니다.
- Signature와 이벤트·뉴스의 섹션 패딩, 제목 크기, 버튼 크기를 조정합니다.
- 푸터는 3열에서 2열로 전환합니다.

### 600px 이하
- 헤더 로고는 90px 너비, GNB 간격과 글자 크기를 더 줄이고 별도 CTA를 숨깁니다.
- 브랜드 패널은 세로 배치, 좌우 20px 수준의 여백으로 전환합니다.
- Signature·이벤트·뉴스의 반복 콘텐츠는 1열로 쌓습니다.
- 푸터는 1열로 쌓고 하단 링크는 줄바꿈할 수 있습니다.

### 480px 이하
- 히어로 컨트롤의 하단 위치와 간격을 한 번 더 조정합니다.

새 서브페이지는 이 breakpoint를 우선 사용합니다. 새로운 breakpoint를 추가할 경우 해당 콘텐츠가 왜 기존 기준으로 대응되지 않는지 설명할 수 있어야 합니다. 반응형은 글자 크기만 줄이지 말고 컨테이너, Grid 열 수, Flex 방향, 버튼 폭, 이미지 비율을 함께 점검합니다.

## 10. Do & Don't

### Do
- CSS 변수와 Pretendard Variable을 우선 사용합니다.
- 기존 메인페이지의 컨테이너, 여백, 둥근 모서리, 버튼 형태를 콘텐츠 역할에 맞게 재사용합니다.
- 오렌지와 짙은 회색의 대비를 브랜드 포인트로 사용합니다.
- 이미지 비율과 제품 이미지의 전체 노출을 확인합니다.
- 링크와 버튼의 목적을 구분하고 실제 내부 페이지·섹션으로 연결합니다.
- hover와 함께 `:focus-visible` 상태를 구현합니다.
- 1024px·600px 기준으로 레이아웃을 점검합니다.
- 공통 CSS를 수정하기 전에 기존 최종 선언과 미디어쿼리를 확인합니다.

### Don't
- 기존 팔레트에 없는 컬러를 새로운 브랜드 컬러처럼 임의로 추가하지 않습니다.
- 코드에서 확인되지 않는 크기·간격·굵기를 고정 디자인 규칙이라고 단정하지 않습니다.
- 오렌지색을 모든 섹션·카드에 무차별적으로 사용하지 않습니다.
- 로고를 텍스트로 대체하거나 제품 사진을 부적절하게 자르지 않습니다.
- hover만 제공하고 키보드 focus 상태를 생략하지 않습니다.
- 새 페이지의 링크를 공식 달콤 사이트로 임의 연결하지 않습니다.
- 메인페이지 파일을 별도 요청 없이 수정하지 않습니다.
- `main.css` 끝에 무분별하게 중복 덮어쓰기 규칙을 추가하지 않습니다.
