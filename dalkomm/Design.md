# Dal.Komm 리뉴얼 프로젝트 — Design System

> 목적: 완성된 메인페이지의 HTML/CSS를 기준으로, 이후 제작할 서브페이지에서도 같은 브랜드 정체성과 UI 규칙을 유지하기 위한 실무 기준 문서입니다.
>
> **분석 기준 파일:** `dalkomm/index.html`, `dalkomm/css/main.css`, `CSS/default.css`, `font/css/pretendardvariable.css`
>
> 이 문서는 현재 코드에서 확인되는 스타일을 기록합니다. 코드에 없는 수치나 컬러는 임의로 표준값처럼 추가하지 않습니다. 메인페이지의 디자인을 변경하기 위한 문서가 아닙니다.

---

## 1. Project Overview

### 사이트 목적

현재 메인페이지는 Dal.Komm과 Dal.Komm.N의 브랜드 소개, 시그니처 메뉴, 이벤트, 새소식을 한 페이지에서 탐색하도록 구성되어 있습니다. 헤더의 주요 메뉴는 BRAND, MENU, STORE, NEWS, APP이며, 별도 CTA인 `창업안내`가 있습니다.

### 디자인 방향

- **브랜드 콘텐츠 중심:** 넓은 배너 이미지와 브랜드별 소개 영역을 사용해 브랜드와 메뉴를 먼저 경험하게 합니다.
- **섹션별 정보 구분:** 브랜드 소개, 시그니처 메뉴, 이벤트, 뉴스는 배경색·이미지·간격을 달리해 구분합니다.
- **간결한 탐색:** 상단 GNB와 드롭다운, 브랜드 탭, 이전/다음 버튼을 통해 콘텐츠를 탐색합니다.
- **큰 이미지와 절제된 UI:** 사진·배너가 시각적 중심이고, 버튼은 둥근 모서리와 단순한 텍스트/화살표로 구성됩니다.
- **반응형 구성:** 데스크톱에서는 여러 카드와 가로 레이아웃을 사용하고, 작은 화면에서는 일부 콘텐츠를 세로로 쌓습니다.

서브페이지는 메인페이지의 구조를 그대로 복제하기보다, 동일한 색·글꼴·컨테이너·버튼·상태 표현을 사용해 한 사이트처럼 느껴지게 해야 합니다.

## 2. Brand Identity

### 시각적 정체성

| 요소 | 코드에서 확인되는 표현 | 적용 의도 |
|---|---|---|
| 핵심 강조색 | `--color-orange-500: #FF671F` | 메뉴 hover, 강조 링크, 이벤트 페이지 표시 등 주목이 필요한 곳 |
| 기본 텍스트 | `--color-neutral-900: #222222` | 제목과 본문 등 기본 텍스트 |
| 흰색 바탕 | `--color-neutral-0: #FFFFFF` | 헤더, 드롭다운, 밝은 콘텐츠 영역 |
| 따뜻한 밝은 바탕 | `--color-neutral-100: #F7F5F2` | 뉴스 카드 및 이벤트 영역 등 콘텐츠 묶음 구분 |
| 브랜드별 대비 | Dal.Komm은 짙은 회색, Dal.Komm.N은 오렌지 배경 | 두 브랜드를 구분하되 동일한 페이지 시스템 안에 배치 |
| 로고 | `dalkomm/img` 안의 제공 이미지 사용 | 로고 텍스트를 임의의 폰트로 재현하지 않고 원본 자산 사용 |
| 사진 | 브랜드/메뉴/이벤트/뉴스 이미지 사용 | 텍스트만으로 설명하기보다 실제 제품과 브랜드 분위기를 전달 |

### 브랜드별 표현

- **Dal.Komm:** `.brand-panel--dalkomm`에 `var(--color-neutral-900)` 배경과 흰색 텍스트를 사용합니다.
- **Dal.Komm.N:** `.brand-panel--dalkomm-n`에 `var(--color-orange-500)` 배경과 흰색 텍스트를 사용합니다. 링크 버튼은 짙은 회색 바탕으로 대비합니다.
- 두 브랜드의 소개 패널은 동일한 `.brand-panel-inner`, `.brand-copy`, `.brand-image` 구조를 공유합니다. 서브페이지에서도 브랜드에 따라 구조를 새로 만들기보다 공통 구조를 재사용하고, 필요한 차이만 modifier 클래스로 분리합니다.

## 3. Design Principles

1. **기존 스타일을 재사용한다.** 새 페이지를 만들 때 먼저 `main.css`의 기존 컴포넌트와 `default.css`의 초기화 규칙을 확인합니다.
2. **컬러는 역할에 맞게 사용한다.** 오렌지는 모든 요소를 칠하는 색이 아니라 hover, 강조, 현재 상태처럼 시선이 필요한 곳에 사용합니다.
3. **정보 위계를 유지한다.** 섹션 제목은 크게, 설명은 한 단계 작게, 카드 설명과 날짜는 더 작게 구성합니다.
4. **여백으로 그룹을 구분한다.** 섹션 내부 패딩, 제목과 본문 사이 마진, 카드 사이 gap을 구분해서 사용합니다. 여백을 임의로 한 값으로 통일하지 않습니다.
5. **이미지 비율을 보호한다.** 메뉴 제품 이미지는 `object-fit: contain`, 카드/브랜드 사진은 콘텐츠에 따라 `cover`를 사용합니다.
6. **상태를 색만으로 구분하지 않는다.** 버튼은 활성 배경, 포커스 outline, 선택 상태 클래스 등 코드에 있는 표현을 함께 사용합니다.
7. **키보드 접근성을 유지한다.** 링크·버튼의 `:focus-visible` 표시를 제거하지 않습니다.
8. **동작과 목적이 일치해야 한다.** 버튼과 링크는 이름에 맞는 내부 페이지·섹션·기능으로 연결합니다.
9. **메인페이지를 기준으로 확장한다.** 서브페이지 제작 중 메인페이지 디자인을 임의로 바꾸지 않습니다. 공통 규칙을 변경해야 한다면 별도 확인 후 적용합니다.

## 4. Color System

### CSS 변수

변수는 `dalkomm/css/main.css`의 `:root`에 정의되어 있습니다.

| 변수명 | 실제 값 | 코드에서 확인되는 역할 |
|---|---|---|
| `--color-orange-500` | `#FF671F` | 기본 오렌지 강조색 |
| `--color-orange-50` | `#FFF0E8` | 연한 오렌지 원색 토큰. 현재 페이지에서 사용 위치는 제한적임 |
| `--color-neutral-900` | `#222222` | 기본 짙은 텍스트, Dal.Komm 패널, 일부 버튼 배경 |
| `--color-neutral-200` | `#E5E1DC` | 경계선용 의미 변수에 연결된 중립색 |
| `--color-neutral-100` | `#F7F5F2` | 부드러운 밝은 배경 |
| `--color-neutral-0` | `#FFFFFF` | 흰색 배경/텍스트 |
| `--color-background-default` | `var(--color-neutral-0)` | 기본 페이지 배경 |
| `--color-background-subtle` | `var(--color-neutral-100)` | 구분이 필요한 부드러운 배경 |
| `--color-surface-default` | `var(--color-neutral-0)` | 기본 UI 표면 |
| `--color-surface-subtle` | `var(--color-neutral-100)` | 보조 UI 표면 |
| `--color-text-primary` | `var(--color-neutral-900)` | 기본 텍스트 |
| `--color-text-inverse` | `var(--color-neutral-0)` | 어두운/강조 배경 위 텍스트 |
| `--color-border-default` | `var(--color-neutral-200)` | 기본 경계선 의미값 |
| `--color-action-primary` | `var(--color-orange-500)` | 주요 액션 색상 의미값 |
| `--color-action-primary-text` | `var(--color-neutral-900)` | 주요 액션 텍스트 의미값 |
| `--color-action-secondary` | `var(--color-neutral-900)` | 보조 액션 색상 의미값 |
| `--color-accent-subtle` | `var(--color-orange-50)` | 연한 강조색 의미값 |
| `--color-accent-strong` | `var(--color-orange-500)` | 강한 강조색 의미값 |

### 사용 규칙

- 기본 텍스트는 우선 `--color-text-primary`를 사용합니다.
- 흰 배경은 `--color-background-default` 또는 `--color-surface-default`를 사용합니다.
- 오렌지 강조는 `--color-orange-500` 또는 목적에 맞는 의미 변수(`--color-action-primary`, `--color-accent-strong`)를 사용합니다.
- 짙은 배경 위 텍스트는 `--color-text-inverse`를 사용합니다.
- CSS 일부에는 `#222`, `#fff`, `#ff671f`, `#888`, `#666`, `#333`, `#aaa`, `#e8e4df`처럼 직접 입력된 값도 있습니다. 이 값들은 기존 구현에서 실제로 쓰이고 있으므로, 서브페이지에 새 색상 체계로 확대하지 말고 공통 토큰과의 관계를 확인하며 필요한 경우에만 재사용합니다.
- `--color-orange-50`, `--color-neutral-200` 등 일부 변수는 정의되어 있지만 모든 페이지 요소에서 일관되게 사용되는 것은 아닙니다. 정의만 보고 사용처가 이미 통일되어 있다고 가정하지 않습니다.

## 5. Typography

### 폰트

- `index.html`은 `../font/css/pretendardvariable.css`를 연결합니다.
- `pretendardvariable.css`는 `Pretendard Variable`을 선언하고 가변 굵기 범위 `45 920`을 설정합니다.
- `body`의 기본 폰트는 `"Pretendard Variable", sans-serif`입니다.
- 제목 로고는 텍스트로 다시 조판하지 않고 이미지 자산(`.brand-logo img`)을 사용합니다.
- Swiper는 슬라이드 동작을 위한 외부 라이브러리이며, 글꼴 규칙은 아닙니다.

### 현재 CSS에 명시된 주요 크기

| 대상 | 데스크톱 기준 | 태블릿/작은 화면에서 확인되는 규칙 |
|---|---|---|
| GNB 주요 메뉴 | `18px`, `font-weight: 500` | `max-width: 1024px`에서 14px, `max-width: 600px`에서 10px |
| 헤더 드롭다운 항목 | `14px`, 보통 `font-weight: 400` | 1024px 이하 11px, 600px 이하 9px |
| 브랜드 제목 텍스트 | `clamp(34px, 2.6vw, 48px)`, 굵기 800, 행간 1.1 | 태블릿 `clamp(30px, 4vw, 40px)`, 모바일 34px. 실제 로고 제목은 이미지 사용 |
| 브랜드 태그라인 | `clamp(18px, 1.35vw, 26px)`, 굵기 600, 행간 1.45 | 태블릿 20px, 모바일 18px |
| 브랜드 설명 | 16px, 굵기 400, 행간 1.65 | 태블릿 14px, 모바일 13px |
| Signature 제목 | 48px, 굵기 500, 행간 1.2 | 모바일 32px |
| Signature 설명 | 18px, 행간 1.5 | 모바일 13px |
| Signature 탭 | 16px | 태블릿은 크기 상속, 모바일 12px |
| 이벤트 섹션 제목 | 40px, 굵기 600, 행간 1.2 | 태블릿 34px, 모바일 28px |
| 이벤트 카드 제목 | 20px, 굵기 600, 행간 1.5 | 태블릿 16px, 모바일 15px |
| 뉴스 섹션 제목 | 40px, 굵기 600, 행간 1.2 | 태블릿 34px, 모바일 28px |
| 뉴스 카드 제목 | 17px, 굵기 600, 행간 1.5 | 태블릿/모바일 15px |
| 뉴스 카드 본문 | 12px, 행간 1.6 | 태블릿 11px, 모바일 12px |
| 뉴스 날짜 | 11px, 행간 1.4, 색상 `#666` | 별도 모바일 크기 변경은 없음 |
| 푸터 회사 정보 | 12px, 행간 1.65 | 태블릿/모바일 10px |
| 푸터 하단 링크 | 11px, 행간 1.5 | 모바일 10px |

### 타이포그래피 적용 규칙

- 페이지 제목, 섹션 제목, 카드 제목, 보조 설명, 날짜 순으로 정보 위계를 유지합니다.
- 기존에 `font-weight`, `line-height`, `letter-spacing`이 함께 지정된 제목은 크기만 복사하지 말고 해당 속성도 함께 확인합니다.
- 한국어 줄바꿈은 `default.css`의 `word-break: keep-all`과 `overflow-wrap: break-word` 규칙을 따릅니다.
- 위 표에 없는 텍스트 크기나 굵기는 임의로 추측하지 않습니다. 새 서브페이지의 제목 수준이 애매하면 메인페이지에서 가장 유사한 콘텐츠 역할의 스타일을 선택합니다.

## 6. Layout & Spacing

### 컨테이너와 정렬

| 영역 | 데스크톱 규칙 | 반응형 규칙 |
|---|---|---|
| 헤더 내부 | `width: calc(100% - 10.2%)`로 재정의, `max-width: none` | 1024px 이하 64px 좌우 여백, 600px 이하 32px |
| 헤더 로고 | 기본 117×30px | 모바일에서 90px 너비 |
| 메인 GNB | 헤더 안 가로 중앙 배치, `gap: clamp(42px, 5.8vw, 108px)` | 1024px 이하 `clamp(24px, 4vw, 48px)`, 600px 이하 12px |
| 브랜드 패널 내부 | `width: calc(100% - 240px)`, `max-width: 1400px`, 중앙 정렬 | 태블릿 좌우 40px, 모바일 좌우 20px |
| Signature 내부 | `width: calc(100% - 120px)`, `max-width: 1800px`, 중앙 정렬 | 태블릿 좌우 32px, 모바일 좌우 16px |
| 이벤트/뉴스 내부 | `width: calc(100% - 120px)`, `max-width: 1600px`, 중앙 정렬 | 태블릿 좌우 32px, 모바일 좌우 16px |
| 푸터 내부 | `width: calc(100% - 160px)`, `max-width: 1760px` | 태블릿 좌우 32px, 모바일 좌우 20px |

### 섹션 간격

- 브랜드 패널: 기본 `min-height: 594px`, 세로 패딩 70px. 태블릿은 최소 높이 제거 후 64px 패딩, 모바일은 48px 패딩.
- Signature: 데스크톱 `padding: 132px 0 110px`; 태블릿 90px/80px, 모바일 64px/60px.
- 이벤트: 데스크톱 `padding: 90px 0 100px`; 태블릿 72px/80px, 모바일 56px/60px.
- 뉴스: 데스크톱 `padding: 64px 0 80px`; 모바일 52px/60px. 태블릿은 64px 좌우 컨테이너와 함께 별도 패딩 규칙을 사용합니다.
- 섹션 제목 아래 간격은 이벤트/뉴스에서 데스크톱 42px, 태블릿 30px, 모바일 24px로 조정됩니다.

### Grid와 Flex

- 브랜드 패널: 데스크톱은 Flex 가로 배치이며 이미지와 텍스트를 나란히 놓습니다. Dal.Komm.N 패널은 이미지와 텍스트 순서가 반대이고, 모바일에서는 `column-reverse`로 배치합니다.
- Signature 탭: Flex 중앙 정렬, 데스크톱 gap 40px, 태블릿 20px, 모바일 12px.
- 이벤트/뉴스 카드: 데스크톱은 `repeat(3, minmax(0, 1fr))` 3열 Grid. 모바일(600px 이하)은 1열로 전환합니다.
- 푸터 상단: 데스크톱은 로고/회사 정보/액션을 3열 Grid로 배치합니다. 태블릿에서는 2열로 줄이고, 모바일은 1열로 쌓습니다.
- 드롭다운은 부모 메뉴를 기준으로 `position: absolute`, `left: 50%`, `translateX(-50%)`를 이용해 메뉴 아래 중앙에 놓습니다.

### 이미지 비율과 자르기

- 히어로 배너: 데스크톱에서 높이 720px, 이미지가 영역을 채우도록 `object-fit: cover`. 1024px 이하에서는 모바일용 배너 이미지를 표시하고 원본 비율을 유지합니다.
- 브랜드 사진: `aspect-ratio: 600 / 380`, `object-fit: cover`, 모서리 24px(태블릿 18px, 모바일 14px).
- Signature 메뉴 이미지: `object-fit: contain`으로 제품 전체가 보이도록 합니다.
- 이벤트 이미지: `aspect-ratio: 1.58 / 1`, `object-fit: cover`.
- 뉴스 카드는 이미지와 텍스트 콘텐츠를 하나의 카드로 묶고, 콘텐츠 영역에 별도 패딩을 둡니다.

## 7. Components

### Header / GNB

- 주요 메뉴는 BRAND, MENU, STORE, NEWS, APP이며 `창업안내` 링크가 별도로 있습니다.
- 주요 메뉴는 18px, 굵기 500으로 시작하며 반응형에서 크기를 줄입니다.
- 메뉴 항목 hover/focus 시 `#FF671F` 계열 오렌지를 사용합니다.
- BRAND, MENU, NEWS 드롭다운은 흰 배경, 아래쪽 둥근 모서리, 항목별 세로 정렬을 사용합니다.
- 드롭다운 너비는 데스크톱 기준 145px(메뉴 드롭다운 기본 규칙은 125px), 1024px 이하 110px, 600px 이하 90px로 지정된 부분이 있습니다. 메뉴별 차이를 임의로 하나의 수치로 통일하지 않습니다.
- 현재 CSS는 헤더/드롭다운에 여러 차례 보정 규칙이 추가되어 있습니다. 서브페이지에서 필요한 규칙을 가져올 때는 해당 요소의 **파일 뒤쪽에 있는 최종 규칙**까지 확인해야 합니다.

### Brand Panel

- `.brand-panel`, `.brand-panel-inner`, `.brand-copy`, `.brand-image`를 기본 구조로 사용합니다.
- Dal.Komm 패널은 짙은 배경, Dal.Komm.N 패널은 오렌지 배경입니다.
- 이미지 모서리는 둥글게 처리하고, 설명과 CTA 사이에는 충분한 간격을 둡니다.
- CTA `.brand-link`는 둥근 캡슐형이며, Dal.Komm.N에서는 어두운 배경과 흰 글자를 사용합니다.

### Signature Tabs / Slider

- 탭은 `.signature-tab`이며 기본 흰색 배경, 어두운 테두리, 둥근 모서리를 사용합니다.
- 활성 탭은 `.is-active` 클래스에 의해 어두운 배경과 흰색 텍스트로 표현됩니다.
- 슬라이드 이미지는 기본 축소 상태 `scale(.66)`, 활성 이미지 `scale(1)`이며 0.3초 전환을 사용합니다.
- 이전/다음 버튼은 원형 테두리 버튼이며 제공된 화살표 이미지 자산을 사용합니다.

### Event Card

- 이벤트 목록은 3열 Grid, 모바일은 1열입니다.
- 이미지 링크는 넘치는 이미지를 감싸고, 카드 이미지 모서리를 둥글게 처리합니다.
- hover 시 이미지가 `scale(1.035)`로 확대됩니다.
- 카테고리는 오렌지색, 제목은 굵고 읽기 쉬운 크기로 구분합니다.
- 페이지 표시 점은 오렌지색이며 현재 항목은 긴 캡슐형으로 표시됩니다.

### News Card

- 뉴스 목록은 3열 Grid, 모바일은 1열입니다.
- 카드 바탕은 `--color-neutral-100`, 모서리는 데스크톱 18px, 태블릿 14px, 모바일 12px입니다.
- 카드 내용은 내부 패딩으로 구분하고, 제목·요약·날짜를 위계에 따라 배치합니다.
- 날짜는 아래쪽에 붙도록 `margin-top: auto`를 사용합니다.

### Buttons / Links

- 주요 브랜드 CTA는 캡슐형 버튼으로, 최소 높이 48px(태블릿 42px, 모바일 40px) 규칙을 가집니다.
- 이벤트/뉴스 더보기 링크는 테두리가 있는 캡슐형이며 hover 시 어두운 배경과 흰색 글자로 반전됩니다.
- 링크에는 텍스트만 두기보다 제공된 화살표 이미지가 함께 사용되는 경우가 있습니다.
- 기본 링크는 `default.css`에서 밑줄을 제거하고 색상을 상속하지만, 컴포넌트에서 목적에 맞는 색과 상태를 별도로 지정합니다.

### Footer

- 로고, 회사 정보, 아이콘 액션, FAMILY SITE, 하단 법적/상담 링크로 구성됩니다.
- 상단 정보는 데스크톱에서 가로 배치, 모바일에서 세로 배치합니다.
- 하단 영역은 상단 경계선과 위쪽 패딩으로 구분합니다.

### 링크 연결 원칙

- 새 서브페이지의 메뉴·CTA는 해당 프로젝트 내부의 페이지, 섹션 ID, 또는 구현된 기능으로 연결합니다.
- **새로 만드는 링크를 기존 공식 브랜드 사이트로 임의 연결하지 않습니다.** 목적 페이지가 아직 없다면 임의의 외부 URL을 넣지 말고, 내부 경로가 확정될 때 연결합니다.
- 현재 메인페이지 HTML에는 공식 사이트로 연결되는 기존 브랜드 CTA/이벤트 링크가 일부 남아 있습니다. 이 문서 작성 과정에서는 메인페이지를 변경하지 않았으며, 서브페이지 제작 시 위 원칙을 적용합니다.

## 8. Interaction

### Hover / Focus

- GNB 메뉴 hover/focus: 오렌지색 `#FF671F`.
- 드롭다운 항목 hover/focus-visible: 오렌지색으로 텍스트 색상 변경.
- 브랜드 CTA hover: `opacity: .88` 및 `translateY(-2px)`로 살짝 떠오르는 느낌을 줍니다.
- 이벤트/뉴스 더보기 hover: 어두운 배경과 흰색 글자로 반전됩니다.
- 이벤트 이미지 hover: 이미지가 `scale(1.035)`로 확대됩니다.
- 뉴스/브랜드 링크는 CSS에서 지정된 색상 전환을 사용합니다.
- 키보드 포커스는 `:focus-visible`로 표시합니다. Signature 버튼은 어두운 outline 2px과 4px offset, 브랜드/이벤트 CTA는 오렌지 또는 `currentColor` 기반 outline을 사용합니다.

### Transitions / Active

- GNB 및 드롭다운: opacity/transform/visibility에 약 0.18초 전환.
- 브랜드 CTA: transform/opacity에 0.2초 전환.
- 이벤트 이미지: transform에 0.35초 전환.
- Signature 메뉴 이미지: transform에 0.3초 전환.
- Signature 탭의 선택 상태는 `.is-active` 및 `aria-pressed`로 표현합니다.
- 히어로 진행 표시는 JavaScript가 슬라이드 변경에 맞춰 너비/위치를 갱신합니다.
- BRAND 드롭다운은 JavaScript에서 `.is-open` 상태와 `aria-expanded`를 갱신합니다. 키보드 Escape 처리도 구현되어 있습니다.
- `default.css`는 `prefers-reduced-motion: reduce` 환경에서 애니메이션/전환 시간을 줄이는 규칙을 포함합니다.

## 9. Responsive Rules

CSS에서 확인되는 주요 기준점은 **1024px 이하**와 **600px 이하**입니다. 히어로 컨트롤에는 추가로 480px 이하 규칙이 있습니다.

### 1024px 이하

- 헤더 높이 60px(후반부의 헤더 최종 보정 규칙 및 미디어쿼리와 함께 실제 적용 순서를 확인해야 함).
- 브랜드 패널은 최소 높이를 제거하고 세로 패딩을 64px로 줄입니다.
- 브랜드 패널 내부는 좌우 여백 40px, gap 42px로 줄입니다.
- 이벤트/뉴스는 3열을 유지하되 카드 간격과 제목 크기를 줄입니다.
- 푸터는 3열에서 2열 구조로 바뀝니다.
- 히어로는 PC 이미지를 숨기고 모바일 배너를 표시하며 이미지 비율을 유지합니다.

### 600px 이하

- 브랜드 패널 내부는 세로 방향으로 쌓고, Dal.Komm.N은 이미지/텍스트 순서를 반대로 배치합니다.
- Signature, 이벤트, 뉴스는 작은 화면에 맞춰 제목·본문 크기와 섹션 여백을 줄입니다.
- 이벤트/뉴스 카드 목록은 1열로 바뀝니다.
- 푸터는 1열로 쌓고 하단 링크는 줄바꿈할 수 있습니다.
- 헤더의 창업안내 링크는 숨깁니다.
- 헤더 로고와 드롭다운, GNB 간격 및 글자 크기를 줄입니다.

### 반응형 제작 규칙

- 메인페이지와 같은 breakpoint(1024px, 600px)를 우선 검토합니다. 새 페이지의 콘텐츠 특성상 추가 breakpoint가 필요하다면 이유를 명시합니다.
- 모바일에서 단순히 글자만 줄이지 말고, Grid 열 수·Flex 방향·좌우 컨테이너 여백·이미지 비율을 함께 확인합니다.
- 데스크톱 전용 줄바꿈은 `.desktop-only`로 숨길 수 있으나, 모바일 문장이 자연스럽게 읽히는지 확인합니다.
- 실제 화면 테스트 없이 “반응형 완료”라고 판단하지 않습니다.

## 10. Do & Don't

### Do

- `main.css`에 정의된 CSS 변수를 먼저 사용합니다.
- 기존 컨테이너 너비, 섹션 패딩, 카드 gap을 유사한 콘텐츠에 재사용합니다.
- 제목/설명/날짜의 정보 위계를 유지합니다.
- 버튼과 링크에 hover와 keyboard focus 상태를 제공합니다.
- 카드 이미지에는 콘텐츠 목적에 맞게 `cover` 또는 `contain`을 선택합니다.
- 공통 컴포넌트는 재사용하고, 브랜드 차이는 modifier 클래스처럼 명시적인 방식으로 분리합니다.
- 링크는 실제 구현된 내부 페이지나 섹션으로 연결합니다.
- 메인페이지를 기준으로 서브페이지를 확장하고, 메인페이지의 디자인은 별도 요청 없이 변경하지 않습니다.
- CSS를 수정하기 전 기존 선택자와 미디어쿼리, 파일 뒤쪽의 덮어쓰기 규칙을 확인합니다.

### Don't

- 기존 팔레트에 없는 새로운 브랜드 컬러를 임의로 만들지 않습니다.
- 코드에서 확인되지 않는 폰트 크기·굵기·행간·간격을 정해진 디자인 규칙처럼 기록하지 않습니다.
- 오렌지색을 모든 버튼과 배경에 무차별적으로 사용하지 않습니다.
- 이미지 로고를 텍스트로 대체하거나 제품 이미지를 불필요하게 잘라내지 않습니다.
- hover 상태만 구현하고 `:focus-visible` 상태를 빼지 않습니다.
- 새 서브페이지의 CTA를 공식 브랜드 사이트로 임의 연결하지 않습니다.
- 기존 메인페이지를 수정하지 않고도 해결할 수 있는 작업에서 메인페이지 디자인을 임의로 바꾸지 않습니다.
- CSS 끝에 중복 덮어쓰기 규칙을 계속 추가하지 않습니다. 이 프로젝트의 `main.css`에는 헤더/드롭다운 등 일부 규칙이 여러 번 선언되어 있으므로, 수정 시 원본 규칙과 최종 적용 규칙을 함께 확인해야 합니다.
